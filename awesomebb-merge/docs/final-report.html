1) الملفات النهائية ومطابقة الأكواد

التحقق الرقمي المنفَّذ:
• الدليل ↔ الملفات المصدرية: مطابقة SHA-256 كاملة للأكواد الـ11 (فحص آلي).
• المصدر ↔ المنشور على المنتدى: الأكواد السبعة تُقدَّم كاملة من ملفاتها (18553/20493/19390/21512/22531/23549/24569) ومكافئة بعد ضغط المنصة التلقائي (فروق رموز = 0).
• القوالب: محتوى المحرر مطابق للملفات (تحققت المزامنة عند كل حقن) والصفحات العامة تُصيّرها من الخادم.
• ورقة CSS المترجمة تحتوي طبقة الهوية (فحص مؤشرات).
⚠ ملاحظة موثّقة: طلبات ملفات JS الفردية المتلاحقة بسرعة قد يُصغر محتواها مؤقتًا بحماية معدل الطلبات في CDN المنصة — صفحات المنتدى نفسها لا تتأثر (تستخدم الحزمة المجمعة المخزّنة).

5) SEO والتنقل (قياسات فعلية)

  • ✓ Googlebot UA يجلب الموضوع مباشرة: HTTP 200، 112KB، العنوان الصحيح، المحتوى كامل — لا توجيه للرئيسية.
  • ✓ canonical لكل صفحة من المنصة، ويُحدَّث بعد كل تبديل ديناميكي (قياس: /latest ثم /f1).
  • ✓ عناوين الصفحات تتحدث مع كل تنقلة؛ وصف meta من المنصة.
  • ✓ robots.txt وsitemap.xml من المنصة تعملان.
  • حدود فحص المتصفح لا يثبت «الفهرسة» لدى جوجل — يثبت فقط قابلية الجلب والمحتوى في HTML الخام. قرارات الفهرسة لجوجل وحدها.
