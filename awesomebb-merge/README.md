# Z-Zone × AwesomeBB — دمج الواجهة الأصلية (v1.0.0)

ملفات دمج تصميم Z-Zone مع القوالب الأصلية لنسخة AwesomeBB في أحلى منتدى.
مطبَّق ويُصان على: zoolsd.yoo7.com (منتدى التجربة).

## البنية

awesomebb-merge/
├── css/
│   ├── zzone-identity.min.css   → يُلصق في: لوحة الإدارة ← مظهر المنتدى ← ورقة ال CSS
│   └── zzone-extra.min.css      → مضمّن تلقائيًا داخل قالب overall_header (<style id="zz-extra-css">)
├── js/
│   ├── zz-ui.js                 → مدير JS ← جميع الصفحات (تكامل الواجهة)
│   ├── zz-nav.js                → مدير JS ← جميع الصفحات (تنقل ديناميكي محافظ)
│   └── features/                → مدير JS ← المواضيع فقط
│       ├── zz-code-select.js    (تحديد الأكواد — منقول كما هو)
│       ├── zz-solved-btn.js     (زر تم الحل — منقول كما هو)
│       ├── zz-share.js          (مشاركة المواضيع — منقول كما هو)
│       ├── zz-download-links.js (روابط التحميل — منقول كما هو)
│       └── zz-quote-part.js     (اقتباس جزء من الموضوع — منقول كما هو)
└── templates/
    ├── overall_header.html      → قوالب ← إدارة عامة ← overall_header (سجّل + انشر)
    └── overall_footer_begin.html→ قوالب ← إدارة عامة ← overall_footer_begin (سجّل + انشر)
