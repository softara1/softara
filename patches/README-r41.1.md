# r41.1 — إصلاح مواضيع المنتدى + احتياط ذكي للشريط والميقا

**التاريخ:** 2026-10-23 — **النطاق:** مدونة عوض تك (almoatn.blogspot.com) وقوالب تعتمد `awad/scripts@2.3.2.js`

## الغرض

1. **مواضيع المنتدى (الإصلاح الأساسي):** ودجت "البرامج/مواضيع المنتدى" في الشريط الجانبي كان يجلب الخلاصة عبر `api.rss2json.com` المحجوب بـ Cloudflare (403)، وسكربته القديم **يمسح بنية الصندوق** عند الفشل فيعرض "خطأ في الجلب" دائمًا. الرقعة تجلب `https://softara.yoo7.com/feed/` **مباشرة** (XML عبر DOMParser) وتعيد بناء الصندوق تلقائيًا إذا أتلفه السكربت القديم (حارس كل 3 ثوان، سقف 3 محاولات جلب كحد أقصى — لا حلقات).
2. **شريط "أخبار ساخنة" + قوائم Mega:** احتياط ذكي فقط — يملأ الحاويات **إن بقيت فارغة** بعد 6/8 ثوان من خلاصات Blogger الرسمية (JSONP). المحرك الأصلي يبقى المتحكم الأول ولا تُستبدل بطاقاته أبدًا.

## كيف يعمل داخل الملف المنشور

الرقعة كتلة واحدة معلّمة `SQ-R41.1-PREPEND` موضوعة **قبل** كود المحرك الأصلي (المحرك لم يُمَس بايتًا واحدًا). التقديم مقصود: إذا تعثر أي سطر لاحق في المحرك تظل الرقعة تعمل (IIFE مستقل + CSS مُحقن برمجيًا بمعرّف `sq-r411-style`).

## التراجع

- **git revert** لكوميت النشر يعيد الملف السابق فورًا.
- أو حذف يدوي: كل ما بين `/* ==== [SQ-R41.1-PREPEND] ...` و`/* ===== ENGINE BELOW (untouched) ===== */`.
- هذا الملف (`patches/r41.1-paste-block.html`) هو صيغة اللصق اليدوي البديلة: تُلصق قبل `</body>` في محرر HTML للقالب إن رُغب بتجاوز ملف المحرك كليًا.
