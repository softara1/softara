# سوفتارا TV — Softara TV

منصة تلفزيون/أفلام/مسلسلات مستقلة لمنتدى سوفتارا (Forumotion — AwesomeBB).

## الملفات
- `softara-tv.html` — الصفحة الكاملة (HTML + CSS + JS + البيانات في ملف واحد)
- `data/softara-tv-data.json` — بيانات المحتوى منفصلة (لمن يريد التحديث عبر jsDelivr)

## التركيب في منتدى أحلى منتدى
1. لوحة الإدارة ← عرض (Display) ← إدارة صفحات HTML (Pages management)
2. أنشئ صفحة جديدة والصق محتوى `softara-tv.html` كاملًا
3. اختر: «لا» لاستخدام ترويسة المنتدى + ضبط الترميز UTF-8
4. احفظ — ستحصل على رابط مثل `/h1-softara-tv`

## تحديث المحتوى
عدّل كائن `STV_DATA` في أعلى `<script>` داخل الصفحة (قنوات/أفلام/مسلسلات/أخبار) — دون لمس أي كود آخر.

> ملاحظة أمنية: لا يوجد أي مفاتيح أو توكنات في هذا المستودع.
