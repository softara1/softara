# سوفتارا TV — Softara TV

منصة تلفزيون/أفلام/مسلسلات مستقلة لمنتدى سوفتارا (Forumotion — AwesomeBB).
**الإصدار الحالي: 2.1** (خمسة مزوّدين فعليين: HLS · MP4 · YouTube · DailyMotion · OK.ru).

## الملفات
- `softara-tv.html` — المنصة الكاملة (HTML + CSS + JS + البيانات في ملف واحد، ~158KB)
- `softara-tv-report.html` — التقرير الفني النهائي المستقل (عربي RTL، الصور مضمّنة، صناديق كود بأزرار نسخ)
- `data/softara-tv-data.json` — بيانات المحتوى v3 للمرجعية (النسخة الفعّالة داخل الصفحة)

## ما الجديد في 2.1
- نظام ترجمة CC موحّد: إيقاف/تشغيل محفوظ التفضيل، لغات فعلية لـ HLS/MP4، وحدود يوتيوب الرسمية معلنة بصدق
- تنظيف جذري للمشغل عند كل تبديل مصدر (مصفوفة 9/9 انتقالات بلا بقايا — فحص DOM فعلي)
- جودات حقيقية مدققة بـ ffprobe + قوائم HLS مشتقة من المانيفست
- مكتبة: 7 قنوات مباشرة + 29 فيلمًا/وثائقيًا + 7 مجموعات (62 حلقة) بروابط مفحوصة 2026-11-02
- معالجة 12 ملاحظة من المراجعة المستقلة + 4 إصلاحات من اختبارات T8
- إتاحة: أهداف لمس ≥44px، بطاقات بلا أزرار متداخلة، شريط أخبار مقروء لقارئات الشاشة

## التركيب في منتدى أحلى منتدى
1. لوحة الإدارة ← عرض (Display) ← إدارة صفحات HTML (Pages management)
2. أنشئ صفحة جديدة والصق محتوى `softara-tv.html` كاملًا
3. اختر: «لا» لاستخدام ترويسة المنتدى + ضبط الترميز UTF-8
4. احفظ — ستحصل على رابط مثل `/hXX-softara-tv`

## تحديث المحتوى
عدّل كائن `STV_DATA` في أعلى `<script>` داخل الصفحة (قنوات/أفلام/مسلسلات/حلقات) — دون لمس أي كود آخر.
دليل الإضافة بالأمثلة الجاهزة لكل مزوّد في القسم 8 من `softara-tv-report.html`.
