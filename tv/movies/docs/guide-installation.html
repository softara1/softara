2تركيب المنصة على منتدى آخر (خطوة بخطوة)

1
اجلب كود نسخة المنتدى

من المستودع: tv/movies/forum/softara-movies-forum.html (عبر صفحة GitHub الخام أو jsDelivr). هذا الكود يشتغل كما هو على أي منتدى — الروابط فيه مطلقة لا تحتاج استضافة.

2
افتح لوحة إدارة منتداك

العناصر الإضافية ← إدارة صفحات HTML ← «إنشاء صفحة HTML جديدة بوضع المتقدم (HTML)».

3
الصق الكود في وضع المصدر

مهم جدًا: الصق في محرر HTML (Source) لا في المحرر المرئي WYSIWYG — المحرر المرئي يشوّه الكود. ولصق كود كبير: استخدم حيلة لصق عبر شريط أدوات المتصفح أو أجزاء.

4
العنوان والخيارات

العنوان: media (يصبح الرابط hXX-media). الخيارات: «لا» لاستعمال أعلى وأسفل منتداك + «لا» لصفحة البداية. ثم «قدّم».

5
تحقق من الصفحة

افتح رابط الصفحة الجديدة: يجب أن تظهر شاشة البداية ثم 43 بطاقة و9 تبويبات مكتبات بدون أخطاء. لو لم تظهر البطاقات فالسبب غالبًا: لصق بالمحرر المرئي أو تعديل غير مقصود في روابط CDN.

تنبيهات مهمة للتركيب
① لا تستبدل @v3.0.0 بـ main — الوسم الثابت يضمن ألا تنكسر صفحتك يومًا بسبب تعديل مستقبلي. ② لا تحذف <meta name="referrer" content="no-referrer"> — يفيد بعض المصادر. ③ على المنتدى الأصلي الصفحة المنشورة رسميًا هي h33-media.

5إضافة قناة يوتيوب كاملة كمكتبة تتحدث تلقائيًا

1
اجلب معرف القناة UC…

افتح صفحة القناة واستخرج channelId من مصدر الصفحة (ابحث عن "channelId":"UC…).

2
مُشتق قائمة الرفع تلقائيًا

قائمة رفع أي قناة = UU + معرف القناة بدون UC. مثال: قناة UCabc123… ← قائمة UUabc123…. تأكد منها بفتح: https://www.youtube.com/playlist?list=UU…

3
أضف لقطة أحدث الفيديوهات

اجلب: https://www.youtube.com/feeds/videos.xml?channel_id=UC… واستخرج أول 10-15 فيديو (id + title) — أضِفها في softara-movies-channels.js:

{"id":"my-channel","cid":"UCxxx…","uploads":"UUxxx…","name":"اسم القناة",
 "handle":"@handle","lib":"docs-ar","note":"وصف","author":"اسم القناة","videos":[
   {"src":"VideoID","title":"العنوان","thumb":"https://i.ytimg.com/vi/VideoID/hqdefault.jpg"}
 ]}
4
أضف مجموعة تقرأ من القناة

في collections داخل data:

{"id":"ch-my-channel","name":"اسم القناة","lib":"docs-ar","kind":"channel",
 "poster":"https://i.ytimg.com/vi/ID/hqdefault.jpg","note":"وصف",
 "source":"قناة رسمية على يوتيوب",
 "episodes":[{"type":"youtube","src":"ID","title":"العنوان","thumb":"…"}],
 "full":{"type":"yt-playlist","src":"UUxxx…","title":"كل فيديوهات القناة (تتحدث تلقائيًا)"}}

ملاحظة: معرف المجموعة يبدأ بـ ch- + نفس id القناة ليكتشف النظام التحديث التلقائي.

لماذا هذه الطريقة أفضل؟ زر «القائمة الكاملة» يعرض كل فيديوهات القناة بما ينشر يومًا ما — عبر مشغل يوتيوب الرسمي، بلا مفاتيح API وبلا بروكسيات هشة، وبضمن شروط يوتيوب 100%.

7نشر التحديث (وسم جديد jsDelivr)

1
عدّل الملف محليًا واختبر

عدّل data/css/js ثم جرّب على نسخة المعاينة قبل الرفع.

2
ارفع إلى GitHub وأنشئ وسمًا
git add -A && git commit -m "Softara Media v3.0.1 — وصف التعديل"
git tag v3.0.1 && git push origin main --tags
3
حدّث صفحة المنتدى

لوحة الإدارة ← صفحات HTML ← h33 ← استبدل @v3.0.0 بـ @v3.0.1 في الروابط (إما كلها أو رابط الملف المعدل فقط — مثلًا ملف البيانات وحده). احفظ بوضع المصدر.

4
تحقق

افتح الصفحة بتجاوز الكاش (Ctrl+F5) وتأكد أن التعديل ظهر وأن الكونسول بلا أخطاء.

8نسخة احتياطية واستعادة

  • الوسم هو النسخة الاحتياطية الأصل: كل إصدار مثبت على GitHub ويمكن جلبه من cdn.jsdelivr.net/gh/softara1/softara@v3.0.0/… أصلًا بأصل للأبد.
  • نسخة ما قبل إعادة البناء: tv-backups/movies-before-rebuild-20261106/ (ملفات v2.2.0 + SHA256SUMS).
  • نسخة النشر: download/softara-movies-v3.0.0/ + لقطة كود صفحة المنتدى كما نُشرت.
  • استعادة كاملة: أنشئ صفحة HTML جديدة والصق كود forum/softara-movies-forum.html من النسخة الاحتياطية — انتهت.

9أسئلة شائعة

أضفت عنصرًا في data لكنه لا يظهر؟ تحقق: فاصلة JSON صحيحة، لا فواصل زائدة قبل ]، ورقّيت وسمًا جديدًا وحديث رابط ملف البيانات. افتح الكونسول — أي خطأ JSON سيظهر هناك.
فيديو يوتيوب يظهر «الفيديو غير متاح»؟ صاحب الفيديو منع التضمين أو الفيديو مقيد العمر — تحقق بفتح الرابط في متصفح عادي. استبدله بمصدر آخر أو أدرجه كتالوجًا.
أريد أفاتار/غلاف لأعمال بلا صورة؟ اترك poster فارغًا — تُبنى بطاقة SVG تلقائيًا باسم العمل.
هل أستطيع إضافة منصة جديدة للتضمين؟ نعم: أضف بناءً لها في softara-movies-player.js (دالة mount + مطابقة في parseSource) — لكن تحقق أولًا من رؤوس X-Frame-Options/CSP في المتصفح قبل الإعلان عنها.
هل الصفحة تؤثر على صفحة Live TV؟ لا إطلاقًا — لا تشارك معها أي ملف معدل؛ استخدم أيقونات مشتركة بالقراءة فقط، وبصمة بيانات Live TV متطابقة بين الوسمين.
