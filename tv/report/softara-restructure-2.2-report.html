كل كود أدناه هو الملف الحرفي الموجود في المستودع، وقد فُحص في متصفح فعلي وهو يحمّل ملفاته من jsDelivr ويعمل بكل وظائفه. طريقة النشر:

  1. لوحة الإدارة ← عرض ← إدارة صفحات HTML ← إنشاء صفحة جديدة.
  2. الصق الكود بوضع المصدر (Source) — لا تتبدل إلى المحرر المرئي إطلاقًا.
  3. اختر: «لا» لاستخدام أعلى وأسفل المنتدى + الترميز UTF-8 → احفظ.
  4. بعد حفظ الصفحتين صار لديك عنوانان /hXX-…؛ إن أردت رابط التنقل المتبادل في التذييل: ضع عنوان كل صفحة في حقل links.companion داخل ملف بيانات الصفحة الأخرى على GitHub، ثم أنشئ وسمًا جديدًا (مثال v2.2.1) واستبدله في الروابط — شرح ذلك في README.

خامسًا: الوظائف التي حُفظت كاملة

  • المزوّدون الخمسة بتنفيذ فعلي: HLS (جودات تلقائية/يدوية + ترجمات مدمجة)، MP4 (جودات متعددة + VTT)، YouTube (IFrame API رسمية + CC تفضيل محفوظ)، DailyMotion وOK.ru (تضمين رسمي).
  • التفكيك الجذري عند أي تغيير: إيقاف ← تفريغ ترجمات ← تدمير مشغل ← إزالة iframes وtracks وBlob URLs والمؤقتات — لا ترجمة معلقة ولا صوت خفي (فُحص بعد كل تبديل).
  • الجودات: زر جودة بقائمة مستويات HLS الحقيقية وملفات MP4 الفعلية، مع حفظ الموضع عند التبديل.
  • الترجمة CC: قائمة لغات فعلية لـ HLS/MP4، قائمة صادقة لليوتيوب، تفضيل محفوظ يطبَّق على كل فيديو جديد.
  • التنقل: السابق/التالي داخل القسم أو قائمة الحلقات، وتشغيل الحلقة التالية تلقائيًا عند الانتهاء (فُحص فعليًا).
  • متابعة المشاهدة (حفظ موضع كل فيلم/حلقة محليًا) + المفضلة (بطاقات وورقة تفاصيل وشارة عدّاد).
  • ورقة تفاصيل العنوان: مواسم/حلقات بمصغرات ونسب تقدم + محتوى مشابه + ملاحظة المصدر.
  • البحث الفوري والتصفية بالتصنيفات في الصفحتين، شريط الأخبار، المقدمة الافتتاحية القابلة للتخطي، السمة الليلية/النهارية، ملء الشاشة + نقرة مزدوجة، صورة داخل صورة، اختصارات لوحة المفاتيح، أهداف لمس ≥44px، دعم قارئات الشاشة.
  • توافق ترقية كامل: مفاتيح التخزين المحلي نفسها — مفضلة/متابعة/ترجمة/سمة المستخدم من v2.1.2 تعمل في الصفحتين الجديدتين (فُحص عبر جلسة واحدة تنتقل بين الصفحتين).
